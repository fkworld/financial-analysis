## 一、结论先行

泡泡玛特已经不是一家单纯依赖盲盒零售的公司，而是一家以 IP 为核心、以产品化和全渠道运营为放大器、以线下体验和新业态延展生命周期的全球化消费内容平台。它的商业本质不是“卖玩具”，而是“持续创造可被反复消费的情绪符号，并通过高频上新、多场景触达和会员体系把情绪消费转化为复购”。

从管理层看，公司仍然带有鲜明的创始人驱动特征。王宁同时担任董事会主席和行政总裁，控制权与经营权高度集中，这种结构有利于战略一致性和全球扩张速度，也意味着关键人物风险和治理制衡压力更高。结合 2025 年海外扩张、IP 商业化延伸和资金用途调整来看，管理层的最大特点是方向清晰、执行速度快、敢于把资源继续压向高回报赛道，但公司也因此更需要证明其成功并非仅由单一超级 IP 或创始人个人判断支撑。

## 二、商业模式分析

## 1. 商业模式的核心：IP 驱动，而非渠道驱动

财报反复强调“IP 始终是本集团业务发展的核心”。从收入结构看，这不是口号，而是已经被验证的经营现实：

- 2025 年总收入 371.2 亿元，同比增长 184.7%。
- 自主产品收入 367.9 亿元，占总收入 99.1%。
- 其中艺术家 IP 收入 334.1 亿元，占总收入 90.0%，高于 2024 年的 85.3%。
- 2025 年共有 17 个艺术家 IP 收入过亿元。
- 头部 IP THE MONSTERS 收入 141.6 亿元，占总收入 38.1%。

这说明泡泡玛特的底层护城河不是门店数量本身，也不是某个单品形态，而是持续孵化、运营和商业化 IP 的能力。公司本质上掌握的是一种“内容工业化能力”：先找到能引发情绪共鸣的角色，再通过设计、故事、场景和渠道把这个角色反复变现。

这类模式的优点有三点：

1. 单个 IP 一旦跑出来，变现链条很长。它可以从手办延展到毛绒、饰品、联名、主题展、乐园、快闪和更多消费场景。
2. IP 的成功可以跨地域复制。财报明确提到公司让 IP 成为“跨越国界、语言和文化的情感纽带”，而 2025 年海外收入高增长已经验证了这一点。
3. IP 平台化之后，公司不必只押注一个角色。17 个过亿 IP 说明公司正在从“爆款公司”向“IP 组合公司”演进。

但这个模式也有明显风险：虽然公司已有 IP 矩阵，收入仍高度集中在头部 IP。THE MONSTERS 单个 IP 占收入 38.1%，意味着泡泡玛特当前仍未完全摆脱“超级 IP 牵引整体估值和业绩”的阶段。若头部 IP 热度回落，新 IP 接力不及预期，增长波动会很大。

## 2. 变现逻辑：产品不是终点，场景和频次才是终点

泡泡玛特的商业模式之所以强，不只是因为拥有 IP，还因为它把 IP 做成了可高频复购、可快速迭代的消费品。

2025 年产品结构变化很能说明问题：

- 毛绒收入 187.1 亿元，同比增长 560.6%，占总收入 50.4%，首次成为第一大品类。
- 手办收入 120.2 亿元，占比 32.4%。
- 衍生品及其他收入 44.7 亿元，同比增长 182.1%。

这背后反映出管理层对商业模式的一次重要升级：公司正在从“收藏型潮玩”向“更日常、更高频、更广泛人群可消费的 IP 商品”迁移。毛绒的意义尤其大，因为它比传统手办具备更高的场景适配性、更宽的人群覆盖和更强的礼赠属性，也更容易从核心粉丝外溢到大众消费。

换句话说，泡泡玛特并不是把 IP 固定在某一种商品形态里，而是不断寻找“哪个品类最能放大当下 IP 的情绪表达”。这使公司拥有更强的产品迭代能力，也提高了爆款 IP 的变现效率。

## 3. 渠道逻辑：直营和数字化结合，尽量把用户留在自己手里

公司 2025 年的另一条主线，是把“消费者触达”做成自己的能力，而不是只依赖第三方渠道分销。

关键证据包括：

- 全球运营 630 家门店，全年净增 109 家。
- 全球运营 2,637 台机器人商店，全年净增 165 台。
- 中国收入 208.5 亿元，占比 56.2%；海外收入 162.7 亿元，占比 43.8%。
- 海外线上销售 79.1 亿元，接近海外零售店的 71.8 亿元。
- 中国内地累计注册会员 7,258 万人，新增 2,650 万人。
- 会员贡献销售额占比 93.7%，会员复购率 55.7%。

这说明泡泡玛特并不是传统意义上的“开店零售商”，而是在搭建一个由直营门店、机器人商店、自研 App、官网、电商平台和会员体系共同组成的全渠道网络。

这个网络的价值在于三点：

1. 直营渠道让公司能直接掌握用户数据、定价权和新品节奏。
2. 自研 App、官网和抽盒机玩法增强了互动感和转化率，不只是卖货，更是在经营用户行为。
3. 会员体系让公司形成复购资产，而不是一次性交易。93.7% 的会员销售占比，意味着用户沉淀已经足够深。

消费公司最难的是把一次爆款购买变成长期复购。泡泡玛特的做法是，让用户不是为了“买一个玩具”而来，而是为了“持续参与一个 IP 世界”。这就是它比普通玩具公司和普通零售公司更值钱的地方。

## 4. 全球化不是简单开店，而是 IP 的跨文化验证

2025 年公司收入高增长的一个核心增量来自海外：

- 海外业务收入 162.7 亿元，同比增长约 292%。
- 美洲收入 68.1 亿元，同比增长 748.4%。
- 欧洲及其他地区收入 14.5 亿元，同比增长 506.3%。
- 海外非流动资产 26.7 亿元，明显高于 2024 年的 5.4 亿元。

这些数字的意义不只是“出海成功”，而是说明泡泡玛特的 IP 已经具备跨文化传播能力。很多中国消费品牌出海，本质上是供应链出海或性价比出海；泡泡玛特更像是品牌内容出海。财报中提到在全球核心城市地标开店、参与梅西百货感恩节游行、与不同国家文化场景做结合，这些动作说明管理层在海外市场追求的不是短期铺货，而是品牌地位和文化影响力。

这是一条更难、但一旦做成更有价值的路。因为它建立的是品牌资产，而不是渠道库存。

## 5. 商业模式的优势与脆弱点

综合来看，泡泡玛特商业模式的优势主要有四个：

1. IP 平台化能力强，已经跑出多个过亿 IP，不再是单一单品故事。
2. 产品形态灵活，毛绒等新品类证明公司能够主动适应更大市场。
3. 渠道掌控力强，直营和数字化触达能力让用户资产沉淀在自己体系里。
4. 全球化验证快，海外市场已经从可选项变成第二增长曲线。

但也要看到几个脆弱点：

1. 头部 IP 集中度仍高，THE MONSTERS 对收入贡献过大。
2. 海外扩张速度很快，供应链、库存、组织管理复杂度同步上升。公司 2025 年存货从 15.2 亿元升至 54.7 亿元，存货周转天数从 102 天升至 123 天，已经反映出全球扩张对运营提出更高要求。
3. 商业模式强依赖持续内容创新，一旦新品节奏或 IP 表达失速，增长可能出现明显回撤。
4. 目前的高增长很大程度来自品牌热度提升和爆款驱动，未来能否平滑波动，取决于公司是否能把“爆发”变成“常态”。

## 三、管理层分析

## 1. 创始人驱动色彩非常强

财报披露，本公司最终控股股东为 GWF Holding Limited，由王宁先生及其配偶杨涛女士控制；同时，王宁担任执行董事、董事会主席及行政总裁。

这说明泡泡玛特目前仍是非常典型的创始人主导型公司。其优点很明显：

- 战略方向统一。
- 组织执行链条短。
- 在全球扩张和新业务布局上能够快速决策。

2025 年的经营结果能明显体现这一点。公司一边继续加码海外市场，一边推动乐园、饰品、烘焙等新业态试验，同时又把毛绒推成第一大品类，还对上市募资用途进行重新分配，把更多资源向海外扩展、IP 商业化平台和营运资金倾斜。这种连续动作说明管理层不是被动跟随市场，而是在主动重配资源、押注下一阶段增长。

对消费公司来说，这类创始人驱动通常优于纯职业经理人驱动，因为品牌调性、审美判断和产品方向很难靠流程完全替代。泡泡玛特本质上是一家需要“审美 + 内容 + 商品化”共同驱动的公司，创始人的持续主导反而可能是竞争优势。

## 2. 管理层最强的能力，不是财务管理，而是资源配置和组织动员

从财报能观察到，管理层至少展现出三种能力：

### 第一，能围绕高势能 IP 快速重构产品与渠道资源

2025 年毛绒占比从 21.7% 大幅升至 50.4%，说明管理层并没有把公司锁死在历史成功路径上，而是及时把资源向更有增长弹性的品类转移。这意味着公司内部不是只有“设计能力”，还有对消费者偏好变化的快速判断能力。

### 第二，敢于在组织成熟前提下做全球扩张

2025 年销售员工从 5,267 人增至 8,685 人，行政及设计开发人员从 1,435 人增至 2,194 人，总员工数达到 10,879 人。配合全球新增 109 家门店，公司明显在加速组织铺设。这种扩张如果没有较强的中后台能力，很容易失控。财报中提到公司持续投入数字化系统、区域仓储和全球供应链网络，说明管理层不仅重前端增长，也在补运营底盘。

### 第三，资本配置开始从“买 IP”转向“做平台、做场景、做海外”

公司对上市所得款项用途进行了调整：减少“收购受欢迎 IP”的未动用部分，转而投向海外扩展、IP 商业化平台建设和一般营运资金。这背后的含义是，管理层判断公司当前更缺的是把现有 IP 放大的基础设施，而不是继续外购内容。这个判断相对成熟，说明管理层已经把泡泡玛特从“找爆款”推进到“建生态”的阶段。

## 3. 管理层治理结构：执行力强，但权力集中度也高

截至公告日，董事会由 9 名董事组成：

- 执行董事 4 名。
- 非执行董事 2 名。
- 独立非执行董事 3 名。

公司在企业管治部分明确披露，其偏离港股企业管治守则中“主席与行政总裁应分设”的条款，理由是王宁作为主要创办人，由同一人士兼任有助于保持领导一致性和整体战略效率。

从公司角度，这一逻辑是成立的。对高增长消费品牌来说，统一领导常常意味着更快的组织反应速度。但从投资者角度，这也意味着几个需要持续观察的问题：

1. 创始人个人判断失误时，内部纠偏机制是否足够强。
2. 董事会虽有 3 名独立非执行董事，但在高增长阶段，独董能否真正形成有效制衡。
3. 当公司从单一品牌成长为全球化平台后，是否还适合长期维持高度集中的治理结构。

财报中董事会强调，重大决策需由多数董事批准，且整体战略、业务、财务和营运政策会经过董事会和高级管理层共同讨论后作出。这说明公司意识到了治理平衡问题，但目前仍处于“以创始人集中领导换效率”的阶段。

## 4. 对管理层的总体评价：强进攻型团队，下一步考验是系统化能力

如果只看 2025 年，泡泡玛特管理层的表现可以概括为一句话：既敢扩张，也能兑现结果。

具体表现为：

- 收入增长 184.7%，远超多数消费公司。
- 海外业务从补充增长极变成核心增长极。
- 毛利率从 66.8% 提升到 72.1%，说明增长并非完全靠粗放投放换来。
- 门店、机器人商店、线上渠道、会员和新业态同时推进，没有出现明显失衡。

但市场最终会追问一个更深的问题：这支团队的能力究竟是“抓住了 2025 年的超级趋势”，还是“建立了可以重复复制的全球化经营系统”？

目前我倾向于认为，泡泡玛特管理层已经证明了前者，正在验证后者。真正的考验不是再做出一个 LABUBU，而是让公司在未来几年里不断复制“新 IP 孵化 - 多品类放大 - 全球化传播 - 线下体验延展 - 会员复购沉淀”的闭环，而且不因单个 IP 降温而失速。

## 四、综合判断

泡泡玛特是一家兼具内容属性、消费属性和零售属性的公司，但最核心的身份仍然是“IP 运营公司”。它的高估值逻辑，不在于门店扩张，也不在于盲盒概念，而在于它是否能够持续把情绪价值做成全球可复制的消费资产。

从 2025 年财报看，这家公司已经具备几个非常突出的特征：

- 它拥有被验证的头部 IP 和正在扩大的第二梯队 IP。
- 它能把同一个 IP 迅速迁移到毛绒、手办、衍生品、展览和乐园等不同场景。
- 它能通过直营渠道和会员体系把爆款热度沉淀为长期用户资产。
- 它的管理层具有很强的资源配置意愿和全球化执行能力。

因此，泡泡玛特最像的不是传统玩具公司，而是“轻资产内容驱动 + 重运营零售执行”的混合体。强项在于增长快、品牌势能强、全球空间大；弱项在于头部 IP 集中、创始人依赖度高、全球扩张后的运营难度会持续抬升。

如果用一句更直白的话概括：泡泡玛特现在最值钱的不是货架上的商品，而是它把 IP 变成全球情绪消费入口的能力；而这套能力能否穿越单个爆款周期，就是公司长期价值的分水岭。

## 五、看多与看空观点

### 看多观点

1. 泡泡玛特最强的地方，不是 2025 年收入翻倍本身，而是高增长背后已经出现平台化特征。17 个艺术家 IP 收入过亿，说明公司并非只靠单一爆款生存；如果未来第二梯队 IP 继续扩容，市场会更愿意把它看成“可复制的 IP 平台”，而不是“阶段性现象级消费股”。
2. 海外扩张正在把公司从中国潮玩品牌推向全球情绪消费品牌。2025 年海外收入占比已达 43.8%，且美洲、欧洲增速极高，这意味着泡泡玛特的 IP 有机会突破中文语境和本土圈层限制。一旦海外消费者对核心 IP 的接受度持续提升，公司长期天花板会明显上移。
3. 会员体系和直营触达网络已经在财报里体现出较强的用户资产属性。中国内地注册会员达到 7,258 万，会员贡献销售额占比 93.7%，复购率 55.7%，这说明公司不是只靠一次性爆款成交，而是在逐步沉淀可反复运营的消费关系。只要新品供给不断，复购机制就有机会支撑更平滑的增长。
4. 毛利率从 66.8% 提升至 72.1%，而且海外收入占比和毛绒品类占比同步上升，说明公司当前并不是靠低价换规模，而是在品牌势能增强时反而放大了盈利能力。如果这种“更快增长 + 更高毛利”的组合还能持续一段时间，市场会倾向于给它更高的品牌型和平台型估值溢价。

### 看空观点

1. 当前高增长仍然高度依赖头部 IP，THE MONSTERS 单个 IP 占收入 38.1%。这意味着只要头部热度回落，或者新 IP 无法及时接力，市场就会质疑公司到底是“拥有平台能力”，还是“恰好抓住了一个现象级 IP 周期”。这种集中度问题，是最容易触发估值压缩的地方。
2. 公司扩张速度很快，但运营复杂度也在同步抬升。2025 年存货从 15.2 亿元升至 54.7 亿元，存货周转天数从 102 天升至 123 天，说明全球化铺货、门店扩张和新品节奏已经开始对库存管理提出更高要求。如果未来需求波动，库存和组织效率可能成为利润率回落的先行信号。
3. 公司当前的利润质量里，有一部分来自业务结构变化带来的顺风。海外占比提升、毛绒大爆发、头部 IP 热度集中释放，共同推动了毛利率和经营杠杆改善。但这些变量未必年年同时成立，一旦产品结构回归常态或海外增长斜率放缓，市场可能会重新审视 2025 年利润率是否具备可持续性。
4. 创始人主导是泡泡玛特的优势，同时也是治理折价来源。王宁兼任主席与行政总裁，且公司由其及配偶控制，这种结构在高速扩张时有利于统一决策，但也意味着关键人依赖高、内部制衡有限。若未来海外扩张、新业务孵化或资本配置出现偏差，市场会把治理集中度重新计入风险溢价。
