## 三、口径与限制

| 项目 | 结论 |
| --- | --- |
| EBITDA 口径 | 公司未直接披露 EBITDA；可依据经营利润与折旧摊销重构 |
| 扣非净利润口径 | 使用 Non-IFRS 经调整净利润代理扣非净利润 |
| 资本化研发可见性 | 年报未单独披露资本化研发或开发支出增加额，无法可靠提取 |
| 资本化摊销可见性 | 年报仅披露收购所得无形资产摊销，无法等同为内部研发资本化摊销 |
| 固定资产折旧率口径 | 当前只能使用“折旧额 / 期末物业、厂房及设备净额”近似估算，且分子含使用权资产及投资物业 |
| 经营性现金流可还原性 | 由于缺少资本化研发现金流信息，无法可靠拆出资本化支出对经营现金流的影响 |
| 现金与债务可勾稽性 | 借款可直接勾稽；2025 年现金储备有管理层披露，但 2024 年同口径未直接披露 |
| 其他待跟进问题 | 若后续要做更严格还原，需要补充开发支出滚动、内部研发资本化明细及使用权资产/投资物业余额 |

## 四、摘要结论

1. **利润高增但含大量口径调整**：2025 年小米营收增长 25.0%，归母净利润增长 76.0%，但经调整净利润仅增长 43.8%，说明投资公允价值变动等非经营项目对表观利润影响很大。
2. **研发和销售投入明显加速**：2025 年研发开支升至 331.3 亿元，销售费用升至 332.1 亿元，增速均高于营收，显示汽车与 AI 业务扩张阶段仍在持续投入换增长。
3. **摘要已足够支撑利润和现金流分析，但不足以严格做资本化研发还原**：固定资产折旧、税率、自由现金流和分部数据都较完整，但内部研发资本化及开发支出滚动未披露，后续还原只能对明确可证实的项目做调整。
