## 三、口径与限制

| 项目 | 结论 |
| --- | --- |
| EBITDA 口径 | 公司未直接披露 EBITDA；本文依据利润总额、现金流补充资料中的财务费用，以及固定资产折旧、使用权资产折旧、投资性房地产折旧、无形资产摊销、长期待摊费用摊销重构 |
| 扣非净利润口径 | 直接采用 A 股年报已披露的扣非净利润，无代理口径问题 |
| 资本化研发可见性 | 新增资本化研发金额和开发支出滚动表均有披露，2025 年可直接确认新增资本化 54.63 亿元，2024 年可比口径为 9.66 亿元 |
| 资本化摊销可见性 | 开发支出滚动表未显示“计入当期损益”或“转入无形资产”金额，不能确认有多少历史资本化研发摊销进入三费 |
| 固定资产折旧率口径 | 年报已披露固定资产原价，因此可按“固定资产折旧 / 期末固定资产原价”使用原值口径，不必退而求其次使用净额口径 |
| 经营性现金流可还原性 | 虽可确认新增资本化研发金额，但财报未直接证明其与现金流量表投资现金流项目逐项一一对应，现金流还原应保持谨慎 |
| 自由现金流口径 | 后续还原文件优先采用分部附注直接披露的“资本性支出”而非单纯用现金流量表支付额替代，以减少 CapEx 口径偏差 |
| 现金与债务可勾稽性 | 较强。流动性资产可按“货币资金 + 交易性金融资产”取最低可追溯口径；债务资本可按公司杠杆比率定义直接勾稽 |

## 四、摘要结论

1. **比亚迪 2025 年的主要矛盾不是收入，而是利润率和现金流同步承压**：营收仍增长 3.46% 至 8039.65 亿元，但毛利率降至 17.74%，扣非净利润同比下滑 20.38%，经营性现金流净额同比下滑 55.69%。
2. **研发强度继续抬升，且资本化明显加快**：2025 年研发投入达到 634.41 亿元，占收入比 7.89%，其中资本化研发 54.63 亿元，资本化率从 1.78% 快速升至 8.61%，这会直接影响三费率和利润质量判断。
3. **固定资产和资本开支仍在高位扩张，但净现金缓冲显著变薄**：固定资产原价升至 5028.67 亿元，2025 年资本性支出 1402.22 亿元；尽管按“货币资金 + 交易性金融资产”口径仍有 108.37 亿元净现金，但较 2024 年的 1027.91 亿元安全垫明显收缩。
